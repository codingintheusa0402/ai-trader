# Trader avatars

One square PNG per trader id (any size; shown as a circle):

    vector.png (대길)  blaze.png (아귀)  atlas.png  echo.png  herald.png

Replace them with your own pictures if you like. A missing file shows the trader's initial instead.
Private pictures can go in `app/static/avatars_local/<id>.jpg` (gitignored); they win over these.
